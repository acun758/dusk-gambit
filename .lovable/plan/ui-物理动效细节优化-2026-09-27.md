# UI 物理动效细节优化

## 目标
在不改页面结构、玩法、数据与服务端逻辑的前提下，为现有旧报纸/王权视觉增加克制的物理触感；以 iPad 和触屏流畅度为优先。

## 本轮采用
1. **重点 Card 触摸反馈**
   - 只用于首页定级赛主卡、可点击入口卡等少量重点卡片，不套到普通信息面板和棋盘。
   - 触摸时按位置产生不超过 2° 的轻微透视倾斜，并出现跟随触点的低亮度径向反光；松手以高阻尼回正。
   - 鼠标设备仅在悬停/按压时启用，手机与 iPad 不运行常驻动画。

2. **按钮物理压感**
   - 共用功能按钮按下缩放至 0.96，增加轻微内阴影；释放时有一次很小的超调回弹。
   - 禁用、加载状态不触发回弹；保留现有 12px 圆角、颜色与文字层级。

3. **抽屉质感**
   - 沿用现有抽屉能力，不重写操作流程。
   - 统一顶部拖拽柄、面板阴影和回弹手感；对弈页底部面板根据松手速度和位移选择收起/展开锚点。
   - 不改变面板内容、按钮位置与业务状态。

4. **低成本边缘光**
   - 重点卡片在激活时使用静态金色边缘光与短暂弥散背光。
   - 不在移动端使用持续旋转的渐变描边，不增加常驻大面积模糊层。

## 本轮不采用
- **胶囊按钮变形为弹窗**：会改变当前弹窗结构与可访问性焦点流，超出纯视觉细节范围。
- **Card 到详情页共享元素转场**：需要介入页面导航生命周期，容易影响现有页面状态与返回行为。
- **按背景亮度自动反色**：需要持续取样或混合模式，文字对比度不可控，也会增加滚动重绘。
- **全站持续旋转流光/呼吸模糊**：与既有旧报纸质感和此前卡顿治理冲突。

## 验收
- 检查首页重点卡、共用按钮、对弈页底部面板。
- 在手机、iPad 竖屏、iPad 横屏、电脑端验证触摸/鼠标反馈、回正、抽屉吸附、无横向溢出。
- 开启“减少动态效果”时关闭倾斜、回弹与流光，只保留静态状态变化。
- 确认对弈落子、页面切换与按钮响应没有新增迟滞。
