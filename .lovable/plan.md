# 微信小游戏核心闭环重构

以已选的“Dark fantasy duel UI”为准，保留黑曜石、古金与猩红的专业棋类质感；先完成页面与真实数据闭环，最后再做真人双端实测。

## 1. iPad 与手机布局重做

- 将底部双层导航合并为单层五入口：王座、对弈、残局、天梯、军械；语言与次级页面移入顶部菜单。
- iPad 竖屏采用宽单列，移除顶部大块留白；棋盘稳定在 480–520px，首屏显示局面、计时和主操作。
- iPad 横屏采用棋盘与实时面板双栏；棋盘 500–520px，右侧同时显示双计时、评估分、棋谱和心智条。
- iPhone 使用 420px 上限的自适应棋盘；实时信息与复盘统一进入顺滑的底部抽屉。
- 首页压缩装饰大图，把玩家段位、钻石、战绩、3+2 快速开局与好友挑战放进首屏。

## 2. 四个核心界面

- **首页**：真实档案、段位进度、钻石、胜负与胜率、快速匹配、好友/对战码入口。
- **对弈页**：真实棋盘、双方身份与 3+2 权威时钟、合法落子、实时棋谱、评估分和连接状态。
- **复盘抽屉**：棋谱、心智、战利品、分析四标签；手机/iPad 竖屏滑动收放，横屏固定为右栏。
- **段位殿堂**：当前段位、赛季战绩、好友可见资料、残局贡献与下一段位解锁路径。

## 3. 好友绑定与点名对战替代方案

- 为玩家生成唯一可搜索账号与短对战码；支持账号搜索、发送好友申请、接受/拒绝、删除好友。
- 好友列表仅展示经双方确认后允许公开的段位、钻石、胜负与在线/对局状态。
- 支持创建 3+2 邀请、复制对战码、输入对战码加入、向好友点名挑战、取消与过期处理。
- 服务端验证挑战双方、邀请码状态、加入权限和对局参与者；客户端不能自行修改好友关系或战绩。
- 数据表全部配置最小权限、行级保护和必要授权；未来微信小游戏接入后，可将微信身份映射到同一好友关系层，无需重写对局逻辑。

## 4. 真实 3+2 对局闭环

- 引入成熟国际象棋规则库，保存并校验 FEN、轮次、合法着法、将军/将死/和棋，移除脚本式模拟落子。
- 将“校验着法、扣减时钟、增加 2 秒、写入棋谱、更新局面”放入单次原子数据库操作，避免并发重复落子。
- 将“判定结果、ELO、钻石、胜负与连胜更新”做成只结算一次的原子操作。
- 保留实时推送；按序号补拉缺失帧，修复网络恢复监听，明确离线、追帧、同步完成状态。
- 首页、对弈页和段位殿堂共享同一份云端档案，并在结算后立即刷新。

## 5. 深度 4–6 残局试炼

- 扩充为分段难度的实战残局集，覆盖一步杀、强制杀、兑换、升变、兵残局、战术防守等主题。
- 每关保存公开题面与目标；标准解法、变例和校验数据仅服务端可读。
- 通关结果返回该关讲解：关键思想、逐步主线、错误候选为何失败、可迁移的实战原则。
- 首次通关只奖励一次；原子更新尝试次数、最佳用时、ELO 与钻石，并直接刷新天梯进度和对应入口。
- UI 提供可视棋盘与盲棋模式、逐步输入/落子、错误反馈、通关讲解面板及“进入对应天梯”。

## 6. 验证与验收

- 检查 iPhone 390×844、iPad 竖屏 834×1194、iPad 横屏 1180×820、桌面 1440×900；确认无横向溢出、遮挡或双层导航。
- 使用两个真实登录身份完成一局 3+2 对局（同一账号不能同时充当双方），验证双方时钟、合法落子、棋谱、评估、结算和三处档案同步。
- 模拟短时断网与页面切后台，确认恢复后按序号补齐棋步、时钟回到服务端值且无重复帧。
- 验证好友申请、账号搜索、对战码加入、点名挑战、资料可见范围和邀请码过期。
- 验证每道新增残局、唯一奖励、讲解展示和段位解锁联动。

## 技术说明

- 页面继续使用现有 TanStack Start 与语义化主题变量。
- 实时同步沿用当前云端实时通道；服务端权威操作通过受保护的服务函数和数据库事务完成。
- 微信好友接口本轮不直接调用；账号搜索与对战码是网页预览和首版小游戏均可工作的替代层。
- 本轮不引入付费、商城或第二套 3D 引擎。
