# 头像上传、实名认证、真人对弈闭环与段位体系

## 1. 自定义头像（上传自己的图片）

- 新增私有存储桶 `avatars`，每位玩家只能读写自己目录下的文件。
- 注册页头像选择器：在现有 12 枚预设图案后增加「上传图片」入口，选择后本地裁切为正方形、压缩到 512×512 再上传。
- 个人资料（天梯页档案区）新增「更换头像」，随时可换。
- 玩家档案新增头像图片地址字段；`PlayerAvatar` 优先显示上传的图片，没有就用预设图案，再没有就按名字派生。
- 对弈页双方玩家条订阅档案变更，对手换头像后即时刷新。

## 2. 实名认证流程

- 档案新增认证状态（未提交／审核中／已认证／被驳回）、真实姓名、证件号后四位、提交时间。
- 注册与档案页的「实名填写」改为认证表单：姓名 + 证件号，提交后校验格式（18 位身份证校验位），通过即标记为已认证并记录时间；格式不符直接给出原因。
- 账户安全区显示认证徽章（已认证／审核中／未认证三种状态），替换原先无条件显示的金色皇冠。
- 约战与天梯入口继续要求已认证，未认证时按钮给出明确指引。

## 3. 对弈真实同步与复盘

- 对弈页统一走服务端仲裁：落子先本地合法性校验，再提交服务端，服务端按序号写入并广播。
- 对手端通过实时订阅接收落子，棋盘、时钟、棋谱同步更新；断线重连按序号补帧。
- 对局结束后弹出结算卡，一键进入复盘页并定位到本局。
- 复盘页逐步回放：可点击棋谱任意一步跳转、前后翻步、自动播放，显示该步的走法记号与评估分。

## 4. 页眉中英双语

- `军械典藏 / Arsenal Collection`、`绝杀典藏 / Victory Archive`、`对局复盘 / Match Review` 等页眉在所有屏幕尺寸都同时显示中英文（英文作小号副标题，不再在小屏隐藏）。
- 页内区块标题同样补齐中英文对照。

## 5. 段位晋升系统

- 每局天梯结束由服务端结算积分：胜负、对手分差、连胜决定加减分，写入档案。
- 积分跨过段位门槛时触发晋升／降段，段位称号与徽章随之更新，并播放晋升动画。
- 天梯页显示当前段位、距下一段位所需积分的进度条、近期升降记录；页眉段位同步刷新。

## 技术要点

- 存储：Supabase Storage 私有桶 + 按 `user_id` 前缀的读写策略，头像地址存 `profiles.avatar_url`。
- 认证字段：`profiles.verify_status`、`id_tail`、`verified_at`，通过服务端函数写入，客户端不可直改。
- 实时：`matches`、`match_moves`、`profiles` 三张表的 Realtime 订阅，落子仍由 `apply_ranked_move` RPC 串行化。
- 段位：复用 `apply_match_result` / `settle_ranked_match`，前端只读结算结果。
